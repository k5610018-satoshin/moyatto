# モヤットのお題49件を授業で使うための点検

対象は配布用コードに入っている標準49題（出来事27、短所・苦手22）です。教師が追加したシートや承認済みの投稿は、教室ごとに内容が異なるため、この一覧の対象外です。

9題はそのまま使えます。40題は、題材の核を生かしながら、セリフ・最初の問い・判定例のいずれかを改めました。特に手当てが必要だったのは「けんか」の自責と他責の食い違い、「断れない」をやさしさとして期待する設定、「給食」の速さを本人に変えさせる方向です。

## 何を見取るか

- 変えずにおく出来事を一つ取り出せ、そこにどんな意味をつけたのかを読み取れる。
- 同じ事実から、互いに意味の違う見方が二つ以上成り立つ。言葉が短くても、具体的な一つの見方をまず受け止める。
- その場に書いていない事情は可能性として扱う。悲しかった、悔しかったという本人の気持ちを訂正しない。
- 次にできることを考えた文では、その前の出来事がどう見え直したかを聴く。下の例と違う言葉でも認める。
- 現実のいじめ、強要、繰り返す排除などの訴えは練習を止めて大人につなぐ。相談に点やクリア条件をつけない。

佐賀県教育センターの教材は、同じ出来事を他の角度から考える活動を示しています。こども家庭庁が掲載するいじめ対応資料は、訴えがあったときに気持ちを尊重して聴くことを扱っています。各お題・評価・修正文は今回の独自の教材点検です。[佐賀県教育センターの教材](https://www.saga-ed.jp/kenkyu/kenkyu_chousa/h26/03_soudan/documents/c_t_2_ikkatu_008.pdf) ／ [いじめの重大化を防ぐための留意事項集](https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/d614d2ed-c695-4fd6-8dc2-2e1662f5ead6/f4cdae28/20251121-councils-ijime-kaigi-d614d2ed-11.pdf)
